# Sistem Informasi Perpustakaan Sederhana

Proyek Final Mata Kuliah Pemrograman Web Framework  
Kelompok 9

## Deskripsi

Sistem Informasi Perpustakaan Sederhana merupakan aplikasi berbasis web yang dikembangkan menggunakan Laravel untuk membantu pengelolaan data perpustakaan, meliputi data buku, kategori, anggota, pengguna, serta transaksi peminjaman dan pengembalian buku.

Project ini dibuat sebagai pemenuhan tugas Final Project mata kuliah Pemrograman Web Framework.

## Teknologi

- PHP
- Laravel
- Database relasional
- Git dan GitHub

## Fitur Utama

- Authentication: login dan logout.
- User Management: pengelolaan akun dan role pengguna.
- Category Management: pengelolaan kategori buku.
- Book Management: pengelolaan data buku.
- Member Management: pengelolaan anggota perpustakaan.
- Borrowing Management: pencatatan peminjaman dan pengembalian buku.
- Dashboard: statistik perpustakaan.

## Aktor Sistem

### Admin
- Mengelola pengguna dan role.
- Mengelola kategori.
- Mengelola buku.
- Mengelola anggota.
- Mengelola transaksi peminjaman.

### Petugas
- Melihat kategori.
- Mengelola buku.
- Mengelola anggota.
- Mengelola transaksi peminjaman.
